# Notes

A place for ideas, drafts, and ongoing notes for the website. Each note is a
Markdown (`.md`) file. Update them freely over time.

## Structure

- `linux/` — Linux notes, commands, configs, troubleshooting
- `ctf/` — CTF writeups, techniques, tools
- `counterstrike/` — Counter-Strike notes
  - `movement/` — movement tech (bhop, surf, strafing, etc.)

## Starting a new note

1. Pick the right folder.
2. Copy `_template.md` and rename it (use lowercase-with-dashes), e.g.
   `linux/systemd-cheatsheet.md`.
3. Fill in the title and start writing.

Tip: keep one idea per file so notes stay easy to find and update.
